# ♟️ Online Multiplayer Chess Game

An interactive **real-time multiplayer chess game** built with **Node.js, Socket.io, and Chess.js**, featuring **drag-and-drop piece movement**, **turn-based gameplay**, and **real-time updates**.

---

## 🚀 Features
✅ **Real-time Multiplayer** – Play against a real opponent with automatic role assignment (White/Black).  
✅ **Drag & Drop Chess Pieces** – Move pieces easily using a **smooth UI**.  
✅ **Valid Move Enforcement** – Illegal moves are prevented using `chess.js`.  
✅ **Spectator Mode** – Additional users can **watch the game live**.  
✅ **Game Over Detection** – Detects **Checkmate, Draw, and Stalemate** conditions.  
✅ **Persistent Game State** – Board updates dynamically for all players.  

---


## 🛠️ Tech Stack
- **Frontend:** HTML, CSS (Tailwind), JavaScript  
- **Backend:** Node.js, Express.js, Socket.io  
- **Game Logic:** Chess.js  
- **Template Engine:** EJS  

---
📜 How to Play
1️⃣ Open the game URL in your browser.
2️⃣ The first player becomes White, the second becomes Black.
3️⃣ Drag and drop pieces to make a move.
4️⃣ The game updates in real-time for both players.
5️⃣ Spectators can watch the game without playing.
6️⃣ The game automatically detects checkmate, stalemate, and draws.
